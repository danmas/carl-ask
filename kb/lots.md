# Карточка: лоты

Отношение: `carl_an.t_auct_total_an`. Читать только его. Не `v_auct_total_an` (на строку зовёт `getauctobjattrib` и соседние функции) и не `auct_total_an` (на wpl2 это проекция той же таблицы, на w2 это другая таблица).

Каталог колонок и хеш: `allowlist.md`, хеш `648f27a0f79ed0a3205b035213bc870a`, 94 колонки.

## Зерно

Одна строка = один лот (`id_auction`), включая повторный раунд перевыставления. Это не одна машина и не один VIN.

## Чем снимок не оперативная таблица

Строки скопированы из `v_auct_total_an` функцией `carl_an.prepare_update_auct_total_an` (ночной вызов около 03:00). На чтении функций нет. «Сейчас» и «активные» — на момент этой пересборки, не `now()`.

В `analytics_table_refresh_log` строки для `t_auct_total_an` нет. `job_name` для свежести лотов не существует. Не подставлять дату из журнала профилей.

## Время

Поле времени само не выбирается. Его надо спросить. Подставлять `dt_end` молча нельзя.

| Колонка | Смысл |
|---------|--------|
| `dt_create` | создание записи лота |
| `dt_start` | старт торгов |
| `dt_end` | окончание торгов. Черновики покупок часто режут год по этой колонке |
| `dt_active` | переход в активные |
| `dt_approve` | одобрение |
| `dt_change_status` | последняя смена статуса |
| `dt_set_lead` | время лидирующей ставки. Тип `timestamp without time zone`, остальные даты снимка — `timestamptz` |
| `period` | text `MM.YYYY`, снят с `dt_change_status` при сборке. Не поле фильтра «за месяц» |
| `commission_dt_start`, `commission_dt_end` | окно тарифа комиссии, не дата продажи |

## Статусы `en_auction_status`

На wpl2: `FAILED`, `SUCCESS`, `DRAFT`, `BUYNOW`, `MODERATED`, `ACTIVE`, `FINISHED`, `CANCELED`.

`auction_type` (`OPEN`, `OFFER`, `BUYNOW`) — формат торгов. Статус `BUYNOW` — исход «купили сразу». Это не одно и то же.

`FINISHED` не продажа. Продажа — только `SUCCESS` и `BUYNOW`.

На wpl2 `FAILED` — 300191 из 350042 лотов. У несостоявшегося лота часто пустые `id_profile_leader` и `summa_lead`. `count` с фильтром по лидеру — это не «все лоты» и не «все продажи». Продажи (`SUCCESS`+`BUYNOW`) — около 41 тысячи, не большинство снимка.

`is_deleted` — character. Живые лоты: `is_deleted = 'N'`. В снимке есть мусор `y` и `Н`, их условие `'N'` не берёт.

## Связи

Одна строка лота.

- к `t_auct_bids_an`: `id_auction = id_auction`. На wpl2 все 350042 различных `id_auction` ставок есть в этой таблице. Со стороны ставок строк больше, чем лотов
- к профилю продавца: `id_profile_seller = prof_*.id_profile`
- к профилю лидера/покупателя: `id_profile_leader = prof_*.id_profile`

В одном запросе не больше одной такой пары.

## Синонимы и допустимые допущения

Показывать в карточке подтверждения, не подставлять молча в обход пустого слота времени.

| Слово | Допущение |
|-------|-----------|
| продано, продажа, покупка, купили | `status IN ('SUCCESS','BUYNOW')`, метрика `count` лотов, не `count(distinct vin)`. Только эти слова. Экспозиция сюда не входит |
| экспозиция | длительность лота, не продажа. Фильтр `status` не ставить. Две даты не выбирать: их спрашивает код. `avg` одной даты (`dt_end`) — не длительность |
| легковые, легковушки | `object_type_top_name = 'Легковые автомобили'` |
| активные, текущие лоты | `status = 'ACTIVE'` и `is_deleted = 'N'` |
| категория товара | `object_type_top_name`, не `object_type_name` и не кузов. Имена топа: Легковые автомобили, ЛКТ, Спецтехника, Грузовые, Другие, Грузовики, Прицепы, Шины, Автобусы, Седельные тягачи, Сборный лот. ЛКТ — лёгкий коммерческий транспорт, не легковые |
| комиссия, которую заплатил покупатель | `sum(applied_commission)` по лотам лидера. Не вызов `getAuctCommission` |
| за 2022 год в отчёте покупок | границы по выбранному полю времени; в черновике фразы 9 это `dt_end >= 2022-01-01` и `< 2023-01-01`, и только если поле времени уже `dt_end` |

Строительная техника и сельхоз — не значения `object_type_top_name`. В оперативной базе это родители `id_object_type` 150 и 122. Колонки родителя на снимке нет. Такой вопрос не закрывать фильтром по слову «сельхоз». Код отказа `MART_MISSING_TYPE_PARENT`.

## Перевыставление

`resale_num` — номер раунда этого `id_auction`. `resale_num_total` — сколько раундов в цепочке. Пока человек не просит уникальную машину, считаются лоты. Уникальный VIN — отдельное допущение, его надо показать.

`vin` в выборки для промпта не класть. Если выдача его содержит, это видно на карточке подтверждения.
